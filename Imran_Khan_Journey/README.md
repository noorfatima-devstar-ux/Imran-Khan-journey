# Imran Khan — The Journey of a Legend

A responsive, interactive biographical website prototype.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Internet access is needed for the externally hosted Unsplash background images; if unavailable, the site includes image fallbacks.

## Theme
Updated to a **Midnight Sapphire + Champagne + Arctic Ivory** palette for a more premium editorial feel.

## Notes
- This is a standalone HTML/CSS/JavaScript frontend prototype.
- Gallery imagery is externally hosted illustrative imagery, not verified archival photographs.
- Check all time-sensitive political/legal details and image licensing before publishing.
- Source links are included in the page for further fact-checking.
